1. Suppose an instruction pipeline has a branch instruction that causes a delay due to flushing the pipeline. What kind of hazard is this?
(A) Data hazard
(B) Structural hazard
(C) Control hazard
(D) Instruction hazard
Answer-C


2. If a system with N pipeline stages has a clock cycle time T, what is the maximum possible throughput?
A) 1 / (N × T)
B) N / T
C) 1 / T
D) N × T
Answer-C
Since each clock cycle takes T time units, the maximum throughput is 1 / T instructions per unit time.

B) 5000 ns
C) 6000 ns
D) 7000 ns
Answer-B
Execution time with delay:
Tp Clock cycle time Total cycles with delay
T_P = 5 * (800 + 200) = 5 *1000 = 5000ns

Occurs due to branch instructions, requiring complex prediction techniques. Incorrect predictions cause pipeline flushing, making it the hardest to manage.

14. A sequential program runs in 120 seconds. When executed on a parallel system, it completes in 30 seconds. What is the speedup ratio S, given by S = ? 

A) 2
B) 3
C) 4
D) 5
Answer-C
Solution:
Speedup Ratio is given by:
S =TN/ Tp
• TN = 120 seconds (execution time on a normal sequential system)
• Tp = 30 seconds (execution time on a parallel system)
So, the correct answer is C) 4.

D) 4.0

Speedup Ratio S is given by:
S= TN
• T₁ = 100 seconds (execution time on a single processor)
•TN = 40 seconds (execution time on N processors)

The correct answer is B) 2.5.
